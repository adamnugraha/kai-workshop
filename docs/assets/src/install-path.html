From an empty VM to the first demo

Six steps, most of them one command

1

Get a VM

Ubuntu 22.04 or 24.04, 8 vCPUs, 32 GB, 100 GB disk; 4 vCPUs and 16 GB for the small profile

2

Install the tools

Docker, k3d, kubectl, Helm and plugins

sudo ./lab.sh install-deps
3

Start the lab

15 to 25 minutes the first time

./lab.sh up
4

Open it

Every address and the password

./lab.sh info
5

Check it

Everything at once, before going on stage

./lab.sh preflight
6

Run the demos

Rush, release, break; then reset for the next round

./lab.sh reset
